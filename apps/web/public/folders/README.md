# Foxy assets for the folder theme

Generated with the built-in ImageGen tool from the supplied original Foxy reference in docs/design/foxmind-user-reference-style/references/04-original-fox.png. No third-party character or remote image URL is used at runtime. All PNGs have actual alpha transparency.

- foxy-welcome.png: full-body seated Foxy waving, same orange/cream fur, dark brown outline and friendly facial proportions; account entry and verification.
- foxy-reading.png: seated Foxy holding an open mint book, same character and rendering; registration and Inicio.
- foxy-logo.png: head-only friendly face, fully visible ears, transparent margin; shared navigation.

Prompt set: preserve the reference identity, warm original 2D illustration, clean outlines, no text/UI/background/frame/extra characters; welcome waves, reading holds a mint book, logo is a face-only square composition. Built-in outputs were inspected before copying. Originals remain under the host generated_images directory; all consumed assets are versioned locally here.

Decorative images use empty alternative text because adjacent headings/brand links supply the meaning. The mascot is kept out of academic answers and grading controls. Interface icons use the existing MIT-licensed Bootstrap asset set.
