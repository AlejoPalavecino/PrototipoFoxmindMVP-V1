# Registros de trabajo

El [estado de FoxMind](../implementation-roadmap.md) identifica los frentes vigentes. El [índice de verificación](../verification/README.md) reúne las pruebas recientes y los recibos históricos por candidato. Los registros de esta carpeta describen el trabajo y las comprobaciones de una sesión determinada.

## Registrar y cerrar una intervención

- Abrí un registro por agente, tarea y sesión con nombre `AAAA-MM-DD-identificador-unidad.md`. Si la sesión no se expone, indicálo.
- Incluí alcance autorizado, rol, rama, worktree y commit inicial. Anotá qué cambió, comandos y resultados observados, fallos, omisiones, commits comprobados cuando correspondan y el primer paso pendiente.
- Cada escritor mantiene su registro. Quien revisa en lectura devuelve evidencia atribuible. Coordinación actualiza el estado del proyecto y el tablero TTP.
- Guardá únicamente evidencia apta para el repositorio, con cuentas y materiales sintéticos. Identificá los ensayos que usaron un proveedor real.
