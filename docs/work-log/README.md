# Registros del trabajo actual

Un registro por agente/tarea/sesión. Nombre: fecha-identificador-real-unidad.md; si la sesión no está expuesta, indicarlo, sin inventar identidad. El coordinador mantiene roadmap y tarea TTP; cada escritor mantiene sólo su registro.

Campos: agente/rol e identificador; fecha/rama/worktree/commit inicial; alcance y autorización vigente; trabajo/superficies; comandos y resultados observados; fallos/omisiones; commits reales si existen; estado y primer paso pendiente.

Crear antes de implementar y cerrar con evidencia. DONE no equivale a código escrito; no borrar fallos para aparentar verificación. Agentes de sólo lectura devuelven los campos y el coordinador persiste atribución, distinguiendo revisor de autor.

No almacenar secretos, credenciales, datos personales reales ni transcripciones. Capturas/fixtures son sintéticos y tienen límites explícitos. Los resultados de proveedores reales no se infieren de mocks.
