# UI: diálogo de recurso Foxy

Estado: implementación inicial completada. Un diálogo con editor controlado, conflicto, selección real de aula y jerarquía, preparación privada, historial, enlaces PDF locales validados y confirmación explícita. Datos de aula histórica se buscan por ID, nunca se usa el destino actual como sustituto.

Componente: 6 PASS; TypeScript web y fronteras PASS. Sin cambios de tests ni datos retenidos. Falta integración, revisión independiente y QA visual real; no se declara verificación visual.
