# Evidencia de la base actual

Esta base sustituye la documentación anterior por pedido del usuario. Se documenta código actual y se distinguen reglas normativas de resultados observados.

- [Recorridos por flujo y rol](flows.md): acciones reales, resultado, capturas y cobertura pendiente; [datos](flows.json).
- [Capturas actuales](../design/current/README.md): índice, viewports y hashes.
- [Comprobaciones](baseline-checks.json): comandos y resultados de esta entrega; no hereda PASS históricos.
- [Retiro documental](documentation-retirement.json): rutas y hashes de lo eliminado, sin conservar contenido ni crear un archivo histórico alternativo.
- [Registro coordinador](../work-log/2026-11-07-root-current-baseline.md): alcance, recursos propios, atribución y handoff.

Entorno local vacío, datos sintéticos, PostgreSQL/S3/ClamAV/Mailpit propios y proveedores IA controlados. No se usaron bases retenidas ni secretos personales; no hubo proveedor real, publicación o despliegue. El recorrido no equivale a auditoría de seguridad, accesibilidad integral ni ejecución de la suite completa. Las ramas no ensayadas siguen explícitas en la matriz.

La matriz contiene 37 entradas PASS, 2 de referencia, 3 limitadas y 4 no ensayadas; cada estado se refiere únicamente a las acciones y al resultado descriptos, no a todas las variantes de la capacidad.
