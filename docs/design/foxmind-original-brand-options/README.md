## Contexto
El usuario no está conforme con el estilo de los seis mockups anteriores. Su aprobación inicial de la propuesta no equivale a aceptación de aquellas imágenes. Este set cambia lenguaje visual, composición y jerarquía sin alterar alcance funcional. Se mantiene la misma información ficticia para comparar las opciones.

Se inspeccionaron y adjuntaron Zorro.png y ZorroH.png de FoxMind/archive/marca-original en las tres llamadas. Sus originales no se editaron. ImageGen los usó como referencias: la fidelidad de las mascotas generadas es aproximada, no una composición pixel-identical. Si se implementa una dirección aprobada, usar los archivos originales como assets, sin redibujarlos.

## Verificación y límites
Tres PNG inspeccionados visualmente: diseños diferenciados, navegación superior, Enseño/Estudio, una acción primaria y sin roles globales, IA, rankings o rachas. No son UI funcional ni pruebas de accesibilidad/reflow. El manifiesto registra dimensiones reales, tamaño y SHA256. No se asume que la tipografía, los colores o el contraste generados sean valores exactos del prompt.
