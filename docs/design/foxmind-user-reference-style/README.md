## Límites
Solo exploración estática, no interfaz funcional ni implementación autorizada. El generador no garantiza tamaños, colores, tipografía ni contraste exactos; no hay QA responsive/teclado/lector de pantalla. Los bordes y sombras deberán normalizarse y la jerarquía de acciones probarse al implementar. La fecha de ejemplos es 22 octubre 2026. Todos los datos de persona, curso y actividad son ficticios.
