# Las cuatro funciones de IA de FoxMind

Cada función tiene un alcance propio. La IA propone o asiste; las decisiones docentes y la publicación conservan sus controles.

| Necesidad | Guía | Detalle y evidencia |
|---|---|---|
| Extraer unidades y temas de un plan aprobado | [Extracción del plan](plan-extraction.md) | [Tarea de extracción](../../../odd/tasks/classroom-ai-extraction.md) |
| Preparar un borrador de actividad | [Generación de actividades](activity-generation.md) | [Tarea de generación](../../../odd/tasks/classroom-activity-ai.md) |
| Orientar el seguimiento de un alumno | [Análisis individual](student-analysis.md) | [Verificación y límites](../../work-log/2026-10-28-root-student-ai-verification.md) |
| Obtener una propuesta privada de corrección | [Corrección asistida](grading-assistance.md) | [Issue #2](../../../odd/tasks/grading-ai-issue-2.md) |

Los contratos de tarea se enlazan desde la raíz del repositorio; las rutas relativas correctas se comprueban con el validador documental. El [estado aceptado](../../implementation-roadmap.md#estado-actual) y la [evidencia](../../verification/README.md) distinguen implementación, pruebas controladas, proveedor real e integración. Ninguno implica despliegue ni cobertura universal de modelos o formatos.

La configuración y las credenciales permanecen en el backend. Compartir proveedor o presupuesto no combina las reglas de privacidad de funciones diferentes: el análisis individual usa métricas anónimas; extracción, generación y corrección tienen entradas documentales o académicas expresamente delimitadas.
